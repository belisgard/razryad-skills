# Изменения

## 0.1.1 (02.09.2026)

Структурная правка по итогам критического разбора текстов глазами новичка. Скиллы те же, путь тот же,
изменилась логика ворот и место записи рисков.

- Одна политика пропуска ворот для всех скиллов и для диалога без скилла: спор один раз, строка в «Риски»,
  делаем. Единственное исключение: сборка без `SPEC.md` не бывает, `razryad-build` пишет короткую спеку
  за 10 минут и только потом собирает. Раньше конституция говорила «делай», а пять скиллов «не начинай».
- Новый раздел «Риски» в `AGENTS.md`: единственное место записи пропусков. Раньше строки `Риск:` писались
  в девять разных файлов. `razryad-retro` проходит по разделу и помечает закрытые.
- Маршрут «пришёл с готовым описанием» без круга: `razryad-prd` в режиме «оформить существующее» сам
  замеряет точку А двумя вопросами и пишет короткий `PROCESS.md`, в `razryad-task` не возвращает.
- Одна таблица стадий в шаблоне `AGENTS.md`; `stage-detection.md` оставляет только правила чтения
  (снизу вверх, пустой файл или раздел равны отсутствию). Раньше было четыре копии с расхождениями.
- `razryad-proto` и `razryad-build` больше не дублируют прогон ассистента: прототип даёт каркас и образец
  входа, прогон и список пробелов только в сборке. Ветка «скрипт» в сборке появилась.
- Раздел «Устройство» считается заполненным только со строкой «Нейросеть внутри:»; дверь после спеки
  ведёт в прототип, а не мимо него. Миновать «Устройство» нельзя даже для скрипта, макет при этом можно.
- Ворота выпуска: посторонний это не агент; перед первыми настоящими данными отдельное «Идём?»;
  у каждого режима выпуска критерий «готово».
- Формула эффекта с «÷ 60» в самом скилле. Жаргон: «коммит» и `git commit` заменены на «сохранить версию»,
  «issue» на сообщение автору, переменные окружения, коннектор и API поясняются при первом упоминании.
- Спека берёт черновики примеров из приёмочных критериев PRD, критерии больше не висят сиротами.
- Evals обновлены под новую политику и место рисков; CONTRACT: 3-6 сценариев, правило пояснения терминов.

Не сделано в этой версии: пример `examples/zayavki-otdela` собран по 0.1.0 и не отражает раздел «Риски»
и новую политику; прогон новичком с нуля по 0.1.1 на живом агенте.

## 0.1.0 (02.09.2026)

Первая версия набора: 12 скиллов пути `razryad` → `razryad-task` → `razryad-prd` → `razryad-spec` →
`razryad-proto` → `razryad-data` → `razryad-build` → `razryad-accept` → `razryad-ship` → `razryad-effect` →
`razryad-demo` → `razryad-retro`, конституция проекта `AGENTS.md`, сквозной пример, evals, линтер.

Проверка: сквозной прогон всех двенадцати скиллов на живом агенте (Claude Code, Sonnet) с агентом-человеком
по справке, результат в `examples/zayavki-otdela/`; пять точечных сценариев из evals (ворота сборки без спеки,
«просто собери без вопросов», анти-маршрутизация двери, приёмка без рабочей версии, настоящий файл в папке).
По итогам прогона: ворота перенесены в конституцию проекта `AGENTS.md`, чтобы работать вне скиллов;
добавлены триггеры двери на «просто собери» и «без вопросов»; правило обращения на «ты».

Не сделано в этой версии:

- `agents/openai.yaml` для витрины Codex (скиллы при этом в Codex работают через `~/.codex/skills`).
- Проверка в Codex на живом агенте, если Codex не установлен у автора на момент выпуска.
