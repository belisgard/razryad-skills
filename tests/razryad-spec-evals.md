# Evals: razryad-spec

Сценарии проверки скилла спецификации. Прогоняются на живом агенте в папке `examples/` или во временной папке.

### 1. Ворота на входе: нет PRD
Вход: папка с `AGENTS.md` и `PROCESS.md`, без `PRD.md`; человек пишет «опиши, как будет работать мой инструмент».
Ожидаем: агент говорит, что для спеки нужен `PRD.md` с вердиктом (скрипт / ассистент / продукт), называет
`razryad-prd` и не начинает интервью о шагах работы.
Провал: агент пишет `SPEC.md` по `PROCESS.md`; сам выбирает тип решения; задаёт вопросы о сценарии без PRD.

### 2. Основной проход, ветка продукта
Вход: папка с `AGENTS.md`, `PROCESS.md`, `PRD.md` с вердиктом «продукт»; человек пишет «давай спеку».
Ожидаем: обзор с вертолёта до первого вопроса; вопросы по одному: кто открывает и что видит первым, главный
сценарий «действие → что происходит», данные на входе и выходе, крайние случаи, что значит «правильно»;
`SPEC.md` по шаблону с разделом примеров, в котором не меньше трёх примеров с конкретными значениями и один
крайний случай; раздел «Устройство» оставлен пустым с пометкой про `razryad-proto`.
Провал: два вопроса в одном сообщении; примеры вида «загружаем файл поставщика, получаем отчёт» без значений;
агент сам заполняет «Устройство»; агент предлагает стек или пишет код.

### 3. Ворота на выходе: примеры без значений
Вход: интервью пройдено, человек на вопрос о примерах отвечает «ну, файл на входе, таблица на выходе, всё просто»
и пишет «сохраняй, идём дальше».
Ожидаем: агент сообщает по форме ворот: не хватает примеров с конкретными значениями, закроем так: он сам
предлагает три черновика примеров по сценарию и просит поправить цифры; спекa не считается готовой без них.
Провал: агент сохраняет `SPEC.md` с общими словами и зовёт `razryad-proto`.

### 4. Настаивание
Вход: после сообщения ворот человек пишет «примеры потом, мне нужен макет сегодня».
Ожидаем: агент один раз называет, какой способ фигни закрывают примеры (нечем проверить, спор «работает или нет»
бесконечен), после повторного «потом» дописывает в конец `SPEC.md` строку `Риск: нет примеров «вход → верный
выход», приёмка будет по ощущению` и передаёт управление `razryad-proto`.
Провал: агент спорит второй раз; молча идёт дальше без строки риска; отказывается.

### 5. Анти-маршрутизация
Вход: папка с `PRD.md`; человек пишет «сделай мне кликабельный макет по PRD».
Ожидаем: агент объясняет одной фразой, что макет делает `razryad-proto` и ему нужна спека с примерами;
предлагает сначала `razryad-spec`, 20-30 минут.
Провал: агент рисует макет из спеки-двери; рисует макет без спеки.
