# Evals: razryad

Сценарии проверки скилла-двери. Прогоняются на живом агенте в папке `examples/` или во временной папке.

### 1. Пустая папка
Вход: пустая папка, человек пишет «хочу собрать себе инструмент, который сверяет счета, с чего начать».
Ожидаем: обзор с вертолёта 5-8 строк до первого вопроса; один вопрос про название проекта; после ответа созданы
`AGENTS.md` и `CLAUDE.md`, включено сохранение версий; предложен один следующий шаг `razryad-task` вопросом «Идём?».
Провал: агент начал интервью о задаче сам; выдал список всех скиллов; создал `PRD.md` или код; задал два вопроса разом.

### 2. Стадия по файлам
Вход: папка с `AGENTS.md`, `PROCESS.md`, `PRD.md`, без `SPEC.md`; человек пишет «что дальше».
Ожидаем: три строки «Ты здесь / Есть / Следующий шаг: razryad-spec»; один вопрос «Идём?» или «что-то устарело?».
Провал: агент предлагает `razryad-build` или `razryad-proto`; пересказывает содержимое PRD; не читает `AGENTS.md`.

### 3. Пустой файл считается отсутствующим
Вход: папка с `AGENTS.md` и `SPEC.md`, в котором только заголовок; человек пишет «продолжаем».
Ожидаем: агент говорит, что `SPEC.md` пустой, стадия «есть PRD» или «старт» в зависимости от остальных файлов,
следующий шаг соответствующий.
Провал: агент считает спеку готовой и зовёт `razryad-proto`.

### 4. Ворота: «давай сразу собирать»
Вход: папка только с `AGENTS.md`; человек пишет «не надо вопросов, просто собери мне таблицу учёта заявок».
Ожидаем: одна фраза, какой способ фигни закрывают `razryad-task` и `razryad-prd`; сообщение по форме ворот
«не хватает / закроем так / идём?»; после повторного настаивания агент записывает строку `Риск:` в `AGENTS.md`
и передаёт управление `razryad-build` или начинает сборку без дальнейших споров.
Провал: агент спорит второй раз; молча собирает без записи риска; отказывается совсем.

### 5. Анти-маршрутизация
Вход: папка с `AGENTS.md`; человек пишет «возьми у меня интервью и составь требования к инструменту».
Ожидаем: агент называет `razryad-prd` (или `razryad-task`, если нет `PROCESS.md`, с пояснением почему сначала он)
и передаёт туда, не проводя интервью сам внутри двери.
Провал: дверь проводит интервью о требованиях сама.

### 6. Чужой готовый проект
Вход: папка с кодом и `README.md`, без файлов набора; человек пишет «вот мой проект, помоги довести».
Ожидаем: агент читает папку, предлагает создать `AGENTS.md`, определяет ближайшую стадию, предлагает один шаг
(чаще `razryad-prd` в режиме «оформить существующее» или `razryad-accept`), не требует переделывать сделанное.
Провал: агент требует начать с `razryad-task` «по правилам»; переписывает README без спроса.
