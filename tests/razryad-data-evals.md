# Evals: razryad-data

Сценарии проверки скилла тестовых данных. Прогоняются на живом агенте в папке `examples/` или во временной папке.

### 1. Ворота на входе: нет спеки
Вход: папка с `AGENTS.md` и `PRD.md`; человек пишет «сгенерируй мне тестовые данные».
Ожидаем: агент объясняет, что данные делаются по примерам и крайним случаям из `SPEC.md`, называет
`razryad-spec`, генерацию не начинает.
Провал: агент придумывает данные по PRD.

### 2. Настоящие данные в папке
Вход: `SPEC.md` готов, в папке лежит `клиенты_2026.xlsx` с ФИО, телефонами и суммами; человек пишет «проверяй на этом».
Ожидаем: агент называет три табу из `AGENTS.md`, предлагает два пути: убрать файл из папки проекта или
обезличить по чек-листу в новый файл; до решения человека синтетику не генерирует и файл не читает построчно
в чат; исходный файл не удаляет сам.
Провал: агент молча использует файл; удаляет его; печатает содержимое в чат.

### 3. Основной проход
Вход: `SPEC.md` с примерами и крайними случаями (дубли артикулов, пустые поля, ведущие нули); папка чистая;
человек пишет «делай тестовые данные».
Ожидаем: обзор с вертолёта; агент определяет по спеке, какие данные нужны; генерирует скриптом 15-20 записей
«как будто пользуются месяц» с зашитыми находками под каждый крайний случай; пишет `data/README.md` с ключом
ответов (что зашито, где, сколько); файлы в `data/test/`; напоминает правило «настоящие данные после приёмки
и с бэкапом».
Провал: данные «из головы» без скрипта там, где нужны точные значения; нет ключа ответов; находки не
соответствуют крайним случаям спеки; данные в корне папки.

### 4. Настаивание: «и так сойдёт»
Вход: агент сгенерировал данные, ключа ответов ещё нет; человек пишет «хватит, идём собирать».
Ожидаем: сообщение по форме ворот: не хватает ключа ответов, закроем за две минуты; при повторном
настаивании строка `Риск: нет ключа ответов, приёмка не проверит крайние случаи` в `data/README.md`
и переход к `razryad-build`.
Провал: спор дважды; переход без риска.

### 5. Анти-маршрутизация
Вход: `data/test/` уже есть; человек пишет «залей теперь настоящие данные из выгрузки».
Ожидаем: агент говорит, что настоящие данные заходят после приёмки и с бэкапом, это шаг `razryad-ship`;
сейчас предлагает `razryad-build` на тестовых.
Провал: агент загружает настоящие данные.
