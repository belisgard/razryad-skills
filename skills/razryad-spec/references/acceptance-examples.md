# Примеры «вход → верный выход»

Пример это будущий тест, который человек прогонит руками на приёмке. Он даёт ответ «прошёл / не прошёл»
без интерпретаций. Спор «работает или нет» кончается, когда есть такие примеры.

## Хороший и плохой пример

| Плохо (не проверить) | Хорошо (проверить за минуту) |
|---|---|
| «Валидация работает» | «Нажимаю “Сохранить” с пустым полем “Имя”: запись не создаётся, под полем подсказка “Заполните имя”» |
| «Скрипт находит дубли» | «Файл поставщика: 3 строки, артикулы АБС-123/1, абс1231, XYZ-9. Каталог: абс1231. Выход: две первые строки со ссылкой на один товар, третья “НЕТ”» |
| «Отчёт считается правильно» | «Вход: 4 заявки за март, суммы 1 200, 3 400, 0, 15 000. Выход: итог 19 600, средняя 4 900, одна заявка с нулём помечена “проверить”» |
| «Ассистент отвечает на письма» | «Вход: файл письма с вопросом о сроке поставки и номером заказа 4471. Выход: черновик с датой из таблицы заказов по 4471, не длиннее 5 предложений, без цифр, которых нет в таблице» |

Признаки хорошего примера:

- вход перечислен значениями, не описан словами («3 строки: …», не «файл поставщика»);
- выход конкретен: число, строка, состояние экрана, имя файла;
- есть «как проверить»: что человек делает и что должен увидеть;
- пример один и тот же для всех, кто его прогоняет; результат не зависит от вкуса.

## Четыре зоны покрытия (для продукта обязательны все, для скрипта и ассистента первые две)

1. **Сценарии.** Главный путь от начала до результата.
2. **Крайние случаи.** Пустое, дубль, битый файл, повтор, нет данных.
3. **Состояния экрана.** Что видно при загрузке, ошибке, пустом списке.
4. **Доступы.** Кто не должен мочь: чужие данные, удаление, запуск без права.

Три примера минимум: один из зоны 1, один из зоны 2, третий по выбору. Если продукт с несколькими ролями,
добавь пример из зоны 4.

## Как предлагать черновики

Человек редко формулирует примеры сам. Предложи три черновика из его сценария и крайних случаев, подставив
правдоподобные значения, и попроси поправить цифры и слова. Спрашивай по одному примеру: «Вот первый, всё так?»

## Чего избегать

- Примеры-повторы: три варианта одного и того же с разными числами. Меняй зону.
- Выход «как ожидается» или «корректно». Всегда значение.
- Пример, который проверяет удобство или красоту. Это не приёмка, это правки в `razryad-build`.
