# razryad-ship: как сделать, чтобы работало без меня и у других?

Инструмент, который живёт на ноутбуке автора, умирает вместе с его отпуском. Этот шаг переносит принятую
версию туда, где ею пользуются другие: по ссылке, по расписанию или как скилл у коллеги. И оставляет
`README.md`, по которому чужой человек запускает инструмент без автора.

## Что это / что не это

Это: выбор режима выпуска по типу решения и тому, кто пользуется; выкладка в режиме плана; проверка чужими глазами.
Это: `README.md` для пользователей без жаргона и проверка, что по нему запускает посторонний.
Это: чек безопасности перед выпуском: секреты, доступ по ссылке, бэкап перед первыми настоящими данными.
Не это: приёмка и доделки. На выпуск идёт версия, принятая в `razryad-accept`, с `TODO.md`.
Не это: расчёт часов и денег, это `razryad-effect`.
Не это: правки функций «раз уж выкладываем». Новые пожелания уходят в `TODO.md`.

## Как ведём себя

- Человек решает, агент делает. Доступы к серверу человек даёт способом, который не оставляет пароль в чате.
- Любые изменения на сервере только через план: показать, дождаться «делай», выполнить.
  Режим плана: в Claude Code Shift+Tab до Plan, в Codex `/plan`.
- Сначала локально без ошибок. На сервер едет только то, что работает на компьютере человека.
- Секреты не в файлах проекта и не в сохранённых версиях. Нашёл: убрать до выкладки.
- Без техно-жаргона в `README.md`: «выложить на сервер», «открывается по ссылке», «положи файл в папку».

## Шаг 0. Контекст

Прочитай `AGENTS.md`, `SPEC.md` (тип решения и раздел «Устройство»), `TODO.md`. Если `TODO.md` нет, приёмки
не было: назови `razryad-accept` и не начинай. Определи режим: продукт с интерфейсом и другие пользователи →
на сервер; рутина по времени или событию → по расписанию; ассистент в агенте → свой скилл для коллеги.
Режимы сочетаются: продукт на сервере может ещё и работать по расписанию.

Обзор с вертолёта до первого вопроса: что получишь (ссылка, расписание или скилл, плюс `README.md`,
по которому запускает чужой), четыре шага, 40-90 минут в зависимости от режима, где сервер нужен, а где нет.
Решаешь ты: куда выкладываем и кому доступ. Делает агент: переносит, настраивает, проверяет.

## Шаги

1. **Режим и адресат.** Один вопрос: кто будет пользоваться и как часто. Подтверди режим из шага 0.
2. **Чек безопасности до выпуска.** Найди секреты и настоящие данные в файлах и сохранённых версиях,
   убери, спроси, кому открыт доступ. → `references/security.md`
3. **Выпуск в выбранном режиме.** План, «делай», выполнение, проверка.
   На сервер → `references/deploy.md`. По расписанию → `references/schedule.md`.
   Свой скилл или агент для коллеги, коннекторы → `references/own-skill.md`
4. **`README.md` для пользователей.** По шаблону, без жаргона, роль вместо ФИО. → `assets/README.template.md`
5. **Проверка чужими глазами.** Человек открывает ссылку в инкогнито и с телефона, либо коллега (или агент
   как посторонний, читая только `README.md`) запускает инструмент. Что не получилось, правишь в `README.md`.
6. **Первые настоящие данные, когда человек готов.** Не обязательно в этот же заход. Бэкап исходников,
   прогон на копии, план отката, потом рабочие данные. → `references/security.md`

## Формат результата

`README.md` в корне проекта для пользователей: что делает одной строкой, кому, как запустить по шагам,
что положить на вход и где взять результат, что делать, если не работает, к кому обращаться (роль).
Плюс результат режима: публичная ссылка, работающее расписание с уведомлением об ошибке или файл скилла,
проверенный на тестовом файле. Секретов в папке нет, в `AGENTS.md` дописано, откуда берутся доступы.

## Ворота

Дальше нельзя, пока не выполнено: посторонний запустил инструмент по `README.md` без подсказок автора;
проверка секретов пройдена; для продукта ссылка открывается в инкогнито и с телефона. Если человек хочет
пропустить `README.md`:

> Без инструкции инструмент остаётся у тебя: уехал в отпуск, и коллеги не могут запустить. Закроем так:
> пять вопросов, `README.md` пишу я. Идём?

Настаивает: запиши в `AGENTS.md` под «Где я» строку `Риск: нет README.md, инструмент запускает только автор`,
и иди дальше.
