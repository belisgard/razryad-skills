# Обезличивание

Обезличенный файл это новый файл, из которого нельзя восстановить человека, контрагента или тайну, а формы,
форматы и крайние случаи сохранены. Исходный файл не трогаем: человек сам решает, убрать его из папки проекта
или оставить вне неё.

## Что считаем настоящими данными

Три табу из `AGENTS.md`:

1. Персональные данные людей: ФИО вместе с контактами, телефоны, почты, паспорта, адреса, даты рождения.
2. Коммерческая тайна: закрытые финансы, цены по контрактам, условия с контрагентами, всё под NDA.
3. Пароли, токены, ключи доступа, логины к системам.

Сомневаешься, тайна ли это: спроси человека, по политике его компании.

## Чек-лист замены

| Поле | Замена | Что сохранить |
|---|---|---|
| ФИО | «Клиент 1», «Сотрудник 3», или роль | количество уникальных людей, повторы |
| Телефон | `+7 9** ***-**-**` или выдуманный валидного вида | формат, наличие пустых |
| Почта | `client1@example.com` | формат, домены компании заменить |
| ИНН, счета, номера договоров | выдуманные валидного вида (длина, контрольные разряды не обязательны) | длина, ведущие нули |
| Названия контрагентов | «Поставщик 1», «Партнёр 2» | повторы, дубли с разным написанием |
| Суммы (если тайна) | округлить или сдвинуть на случайный процент | порядок величины, нули, отрицательные |
| Даты | сдвинуть все на одинаковое число дней | интервалы, порядок событий |
| Адреса | «г. Город, ул. Улица, д. 1» | наличие, пустые |
| Свободный текст (письма, комментарии) | переписать по смыслу с выдуманными фактами | тема, длина, тон |

## Проверь не только содержимое

- Имена файлов: `выгрузка_ИвановИИ_март.xlsx` тоже персональные данные.
- Пути и названия листов в книгах.
- Скрытые листы, скрытые колонки, примечания к ячейкам.
- Метаданные документов (автор, компания).
- История чата: если файл уже читался в чат построчно, скажи об этом человеку.

## Как делать

Скриптом, не руками: замены должны быть согласованными (один и тот же человек везде «Клиент 7»).
Результат в новый файл в `data/test/`, исходный файл не изменяется. После замены пройти по файлу глазами
на случайных 10 строках: не осталось ли имён в свободном тексте.

## Что делать с исходным файлом

Предложи человеку два пути и дождись решения:

- убрать файл из папки проекта (перенести туда, откуда взят), в проекте остаётся только обезличенная копия;
- оставить вне папки проекта и сослаться на путь в `data/README.md` без копирования.

Удалять файл сам агент не должен. Если он остаётся в папке проекта по решению человека, строка `Риск:`
в `AGENTS.md`.
