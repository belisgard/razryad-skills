# Вопросы после показа

После трёх минут показа обычно две минуты вопросов. Жёсткие вопросы задают не чтобы завалить, а чтобы понять,
реально ли это. Конкретный ответ с цифрой и сроком всегда сильнее «ну, наверное, можно».

## Три типа вопросов

### «А если…»
Вопрос про расширение: на весь отдел, на другие филиалы, на соседний процесс.

Форма ответа: «Реализуемо. Нужно [что именно: доступ к такой-то таблице, ещё один формат файла].
Оценка: [часов работы]. Пока не проверено.» Масштаб экономии называть как оценку: «при N людях с таким же ритмом
примерно × N, замер не делал». Не обещать сроки, которых нет в `TODO.md`.

### «А это безопасно?»
Вопрос про данные и доступы. Руководство спрашивает про утечку клиентской базы, персональные данные, тайну.

Форма ответа: три предложения. Где лежат данные. Что уходит в модель и что нет (из `README.md` раздел «Данные»).
Кто имеет доступ по ссылке. Нормальный ответ: «Детали готов обсудить с безопасностью». Ненормальный: «да всё
нормально» без конкретики. Если персональные данные обезличены, сказать как.

### «Не знаю»
Вопрос, на который нет ответа. Это нормально.

Форма ответа: «Хороший вопрос, сейчас не готов ответить. Проверю и пришлю [канал] до [дата]». Записать вопрос
в `TODO.md` раздел «потом» сразу после показа.

## Как готовить заготовки

Агент задаёт человеку один вопрос: «Какие два вопроса ты боишься услышать?» Для каждого готовится ответ
в одну-две фразы по форме выше. Плюс три типовых из этого файла. Больше пяти заготовок не нужно.

## Чего не делать в ответах

- Оправдываться: «не успел», «времени было мало». Вместо этого: «это версия один, дальше [план]».
- Уходить в технику: названия технологий, как устроено внутри. Вместо этого: что делает и для кого.
- Спорить с вопросом. Вместо этого: принять, ответить по форме, при необходимости «проверю и пришлю».
- Обещать цифру, которой нет в `EFFECT.md`.

## Если сломалось на показе

Фраза: «На демо бывает, дома работало». Порядок: второй заранее подготовленный сценарий → запись экрана →
рассказ по результату из `README.md`. Не чинить в эфире: две минуты отладки на глазах у аудитории хуже
честного переключения на запись.
