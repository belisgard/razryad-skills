# Маршруты по набору

Один путь, три темпа. Скиллы и ворота одни и те же, отличается только то, сколько шагов человек проходит за раз.

## Своим темпом (по умолчанию)

Один скилл за подход. Человек возвращается, когда готов, `razryad` определяет стадию по файлам и предлагает
следующий шаг. Подходит тому, кто делает инструмент между рабочими задачами.

## Интенсив за неделю

Для группы, которая собирает инструменты за пять рабочих дней. Вечером каждого дня закрываются ворота дня.

| День | Скиллы | Ворота дня |
|---|---|---|
| 1 | `razryad`, `razryad-task`, `razryad-prd` | есть `PROCESS.md` с замером и `PRD.md` с вердиктом |
| 2 | `razryad-spec`, `razryad-proto` | `SPEC.md` с примерами «вход → выход» и разделом «Устройство» |
| 3 | `razryad-data`, `razryad-build`, `razryad-accept` | главный сценарий проходит на тестовых данных, есть `TODO.md` |
| 4 | `razryad-ship`, `razryad-effect` | другой человек запускает по `README.md`, есть `EFFECT.md` |
| 5 | `razryad-demo`, `razryad-retro` | показ на 3 минуты прошёл, `JOURNAL.md` записан |

## У меня уже есть проект

Человек приходит с папкой, где что-то уже сделано без набора. Действия:

1. Прочитай папку: какие файлы есть, есть ли описание задачи, спека, тесты, README.
2. Сопоставь с таблицей «Где я» в `AGENTS.md`. Если конституции нет, предложи создать её первым делом.
3. Не заставляй переделывать сделанное. Если есть описание задачи в свободной форме, предложи `razryad-prd`
   в режиме «оформить существующее»: скилл читает, что есть, задаёт только вопросы про недостающее и сам
   замеряет точку А двумя вопросами, в `razryad-task` не возвращает.
4. Один следующий шаг. Не список всего, чего не хватает.

## Второй проект

После `razryad-retro` человек заводит новую папку и снова начинает с `razryad-task`. Конституцию для нового
проекта `razryad` создаёт из шаблона, а раздел «Термины и стандарты» предлагает перенести из прошлого проекта.
