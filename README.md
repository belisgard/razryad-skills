# razryad-skills

Путь первого продукта с ИИ-агентом. Двенадцать скиллов для Claude Code и Codex, которые ведут человека
без программистского опыта от выбора задачи до инструмента, который работает без него, и до честной цифры
эффекта. На каждом шаге ворота: дальше нельзя, пока не закрыт конкретный пробел.

Набор написан на русском, для людей, которые решают, а не пишут код. Ты ставишь задачу, отвечаешь на вопросы
и проверяешь результат. Агент делает.

## Зачем

Первый инструмент с ИИ-агентом обычно заканчивается одинаково. Собрали за вечер, показали, через месяц никто
не пользуется. Причины повторяются от человека к человеку, и все они не про код:

| # | Способ сделать фигню | Какой шаг закрывает |
|---|---|---|
| 1 | Решение размытой проблемы: нет пользователя и цифры боли | `razryad-task`, `razryad-prd` |
| 2 | Первая задача слишком большая: живые данные из систем, три интеграции | `razryad-task` |
| 3 | Пропущена спека: агент угадывает, человек соглашается | `razryad-spec` |
| 4 | Не определено «правильно»: нет примеров «вход → верный выход» | `razryad-spec`, `razryad-accept` |
| 5 | Сырой инструмент кормят настоящими данными | `razryad-data` |
| 6 | Размытая обратная связь агенту и правки пачками | `razryad-build` |
| 7 | Переусложнение: интерфейс вместо папки с агентом, нейросеть вместо скрипта | `razryad-prd`, `razryad-proto` |
| 8 | Вера агенту на слово «всё работает» | `razryad-accept` |
| 9 | Нет сохранённых версий, откатиться некуда | `razryad-build` |
| 10 | Инструмент остаётся на ноутбуке автора | `razryad-ship` |
| 11 | Эффект не измерен, через месяц бросили | `razryad-task`, `razryad-effect` |
| 12 | Выводов нет, на втором проекте те же ошибки | `razryad-retro` |

## Путь

Каждый скилл отвечает на один вопрос, оставляет один файл в папке проекта и имеет условие выхода.
Стадия проекта видна по файлам, ничего запоминать не нужно: скилл `razryad` смотрит на папку и называет
следующий шаг.

| Фаза | Скилл | Вопрос | Файл |
|---|---|---|---|
| Вход | `razryad` | Где я и что дальше? | `AGENTS.md`, `CLAUDE.md` |
| Замысел | `razryad-task` | Что делать первым и как это идёт сейчас? | `PROCESS.md` с замером «точки А» |
| Замысел | `razryad-prd` | Что строим, для кого, зачем? Скрипт, ассистент или продукт? | `PRD.md` |
| Проект | `razryad-spec` | Как это работает и что значит «правильно»? | `SPEC.md` с примерами «вход → верный выход» |
| Проект | `razryad-proto` | Это то, что нужно? Как устроено, нужна ли нейросеть? | макет или каркас, раздел «Устройство» |
| Проект | `razryad-data` | На чём проверять безопасно? | `data/test/`, ключ ответов |
| Сборка | `razryad-build` | Как заставить работать и как говорить с агентом, когда не так? | рабочая версия, сохранённые версии |
| Сборка | `razryad-accept` | Готово ли? | `TODO.md` |
| Жизнь | `razryad-ship` | Как сделать, чтобы работало без меня и у других? | `README.md`, ссылка или расписание |
| Жизнь | `razryad-effect` | Сколько сэкономили честно? | `EFFECT.md` |
| Жизнь | `razryad-demo` | Как показать за 3 минуты? | `DEMO.md` |
| Жизнь | `razryad-retro` | Что я понял? | `JOURNAL.md` |

Правила работы над проектом (человек решает, агент делает; по одному вопросу; одна правка за раз;
сначала тестовые данные; три табу по данным; точный счёт только кодом; честная приёмка) первый скилл
записывает в `AGENTS.md` проекта. Все остальные скиллы читают этот файл первым делом. Файл общий для
Claude Code и Codex: `CLAUDE.md` содержит одну строку, которая его подключает.

## Как начать

Открой пустую папку в Claude Code или Codex и напиши:

> хочу собрать себе инструмент, с чего начать

Скилл `razryad` заведёт папку и проведёт к первому шагу. Если у тебя уже есть проект, открой его папку
и напиши «что дальше»: скилл определит стадию по файлам.

Первый шаг (`razryad-task`) занимает 20-40 минут. Весь путь до работающего инструмента с цифрой эффекта:
от одной рабочей недели в темпе интенсива до месяца между делом. Маршруты описаны внутри скилла `razryad`.

## Установка

### Claude Code, как плагин

```
claude plugin marketplace add belisgard/razryad-skills
claude plugin install razryad-skills@razryad-skills --scope user
```

Команды будут вида `/razryad-skills:razryad`, `/razryad-skills:razryad-task`. Обновление: `claude plugin update razryad-skills`.

### Claude Code или Codex, копированием

Скопируй папки из `skills/` в каталог скиллов:

- Claude Code, для всех проектов: `~/.claude/skills/`; для одного проекта: `.claude/skills/` внутри проекта.
- Codex: `~/.codex/skills/`.

Тогда команды короткие: `/razryad`, `/razryad-task`. Обновление: скопировать заново.

### Попросить агента

Вставь в чат Claude Code или Codex:

> Установи набор скиллов из репозитория github.com/belisgard/razryad-skills: склонируй его во временную папку,
> скопируй все папки из `skills/` в мой каталог скиллов (`~/.claude/skills/` для Claude Code, `~/.codex/skills/` для Codex),
> сохрани адрес репозитория как источник обновлений и проверь, что скилл `razryad` виден. Потом удали временную папку.

## Что внутри репозитория

```
skills/<name>/SKILL.md        сам скилл: шаги, формат результата, ворота
skills/<name>/assets/         шаблоны файлов, которые скилл создаёт в проекте
skills/<name>/references/     подробности: критерии, чек-листы, примеры
examples/                     сквозной пример проекта, собранный самими скиллами
tests/<name>-evals.md         сценарии проверки поведения каждого скилла
scripts/validate.py           линтер репозитория
CONTRACT.md                   контракт для авторов скиллов
```

## Как устроен скилл

Каждый `SKILL.md` короткий: до 150 строк. Внутри: что это и что не это; как ведём себя; контекст, который
агент читает перед первым вопросом; шаги по одному вопросу; формат файла-результата; ворота; следующий шаг.
Подробности в `references/`, шаблоны в `assets/`. Папка скилла самодостаточна, её можно скопировать отдельно.

## Честные границы

- Скиллы дают структуру и вопросы, а не гарантию результата. Цифры эффекта, которые получаются на пути,
  это оценки с формулой и датой повторного замера, не факт.
- Набор рассчитан на первые проекты: один процесс, один автор, данные в файлах или тестовые. Для интеграций
  с корпоративными системами и командной разработки нужны другие инструменты поверх.
- Агент не встраивается в твой продукт. Если внутри решения нужна модель, это отдельная модель по API,
  и скилл `razryad-proto` помогает прикинуть, нужна ли она и сколько стоит.
