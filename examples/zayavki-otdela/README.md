# Реестр заявок

Общий список заявок от менеджеров со статусами: внёс один - сразу видят остальные, без пересылки в чатах.

**Для кого:** менеджер (пользуется много раз в день, по мере поступления заявок), владелец (заходит пару раз в день посмотреть общую картину). **Как часто:** весь рабочий день.

## Как запустить

1. Открой ссылку: https://<адрес-страницы> - работает в браузере на компьютере и телефоне, без логина и пароля.
2. Чтобы добавить заявку: нажми «Новая заявка», выбери своё имя из списка, впиши клиента и что нужно, выбери срок в календаре, если знаешь сумму - впиши, нажми «Сохранить». Клиент, что нужно и срок - обязательные поля.
3. Чтобы сменить статус заявки (например на «в работе», «сделано» или «отменено»): выбери новый статус прямо в строке списка, в выпадающем списке.
4. Чтобы увидеть только нужные заявки: воспользуйся фильтром по статусу вверху списка.

## Где результат

Список виден сразу на странице по ссылке и обновляется сам за несколько секунд - обновлять страницу руками не нужно. Данные хранятся в Google Таблице; владелец может открыть её напрямую и посмотреть или выгрузить.

## Если не работает

- Не открывается ссылка → проверить интернет-соединение, обновить страницу (F5).
- Заявка не сохраняется → проверить, что заполнены клиент, что нужно и срок - без них форма подсвечивает пустое поле и не сохраняет.
- Новая заявка или смена статуса не видна у других → подождать несколько секунд (автообновление); если не появилось за минуту, обновить страницу.
- Заявку внесли дважды по ошибке → это не баг, удаления нет; переведи лишнюю заявку в статус «отменено» вручную.
- Ошибка с текстом на экране → скопировать текст целиком и отправить владельцу.

## К кому обращаться

Владелец инструмента (ведёт учёт заявок).

## Что инструмент не делает

- Не считает деньги и итоговые суммы по заявкам, только хранит сумму заявки как есть.
- Не напоминает автоматически, если заявка долго висит без движения.
- Не хранит историю переписки с клиентом и его контакты (телефон и т.п.) - только имя клиента и суть заявки.
- Не разделяет права: любой из четверых видит и может изменить весь список.
- Не удаляет заявки - единственный способ убрать заявку из активных - статус «отменено».

Сейчас известное ограничение: сумма отображается без пробела между тысячами (например «100000», а не «100 000»). На работу списка не влияет, доработка в `TODO.md`.

## Данные

Инструмент хранит: имя менеджера, клиента (название, без контактов), что нужно, срок, сумму (может быть пустой), статус. Персональные данные людей (ФИО с контактами, телефоны, паспорта) в него вводить не нужно. Инструмент без нейросети внутри - ничего никуда за пределы Google Таблицы владельца не уходит.
