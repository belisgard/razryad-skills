# Примеры

## zayavki-otdela: реестр заявок отдела продаж

Сквозной пример пути по всем двенадцати скиллам. Собран самими скиллами: агент вёл проект в Claude Code
(модель Sonnet), а роль человека играл второй агент по короткой справке: координатор отдела продаж
в небольшой торговой компании, три менеджера, заявки собираются руками в таблицу по 40 минут в день,
сервера и ИТ-отдела нет. Все имена, компании и суммы выдуманы.

Что лежит в папке и каким скиллом создано:

| Файл | Скилл | Что показывает |
|---|---|---|
| `AGENTS.md`, `CLAUDE.md` | `razryad` | конституция проекта, заполненные строки «Задача» и «Тип решения», таблица «Где я» |
| `PROCESS.md` | `razryad-task` | инвентарь рутин, критерии первой задачи, карта «как сейчас», точка А формулой |
| `PRD.md` | `razryad-prd` | пять разделов, приёмочные критерии, вердикт «продукт с интерфейсом» с обоснованием |
| `SPEC.md` | `razryad-spec`, `razryad-proto` | сценарий по шагам, крайние случаи, три примера «вход → верный выход», раздел «Устройство» без нейросети и с оценкой 0 ₽ |
| `data/README.md`, `data/test/` | `razryad-data` | синтетические заявки за месяц и ключ ответов с зашитыми дублями |
| `TODO.md` | `razryad-accept` | таблица вердиктов с доказательствами, прогон примеров, три корзины |
| `README.md` | `razryad-ship` | инструкция для менеджеров без жаргона |
| `EFFECT.md` | `razryad-effect` | точка Б, формулы с подстановкой, стоимость часа как ориентир, дата повторного замера |
| `DEMO.md` | `razryad-demo` | сценарий трёх минут, заготовки на вопросы, чек-лист, репетиция |
| `JOURNAL.md` | `razryad-retro` | что сработало, где застрял, правила в конституцию, отзыв набору, второй проект |

Что в примере условно: код страницы и хранилища не включён, адреса опубликованной страницы и хранилища
заменены на `<адрес-страницы>` и `<адрес-хранилища>`, проверка ссылки «в инкогнито и с телефона» была
проиграна, а не выполнена. Всё остальное, включая формулировки и цифры, оставлено как вышло из прогона,
чтобы было видно реальное поведение скиллов, а не отредактированный идеал.

Как воспроизвести: открыть пустую папку с установленным набором, написать «хочу собрать себе инструмент,
с чего начать» и отвечать на вопросы. Сценарии проверки поведения каждого скилла лежат в `tests/`.
